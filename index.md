# HA Backups

HA Backups is a personal application used to upload encrypted backups of a self-hosted Home Assistant installation to Google Drive.

The application uses rclone and the Google Drive API.

It requests the `drive.file` OAuth scope, limiting its access to files created or explicitly authorized for the application.

The application is intended for private use and is not offered as a public service.
